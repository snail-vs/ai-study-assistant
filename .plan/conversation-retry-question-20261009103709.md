# 会话重试区展示原问题

## 目标
重试入口展示将重新回答的原问题，而不是 Provider 原始错误。保留已有重试流程、失败轮次关联、残缺答案标记和不可重试错误提示。

## 实施
- App.vue 根据 retryRun.questionMessageId 在当前会话用户消息中读取原问题；重试区展示该问题及现有按钮，可重试时不显示原始连接错误。
- 使用独立的中性/绿色重试区样式，长问题换行；删除不再使用的错误区按钮样式。
- 更新 App 的真实组件回归，覆盖历史问题与失败问题区分、原问题显示而非错误、点击重试仍使用原轮次。
- 用本地真实前端配合受控 API fixture 验证截图、刷新恢复和按钮行为；不操作生产会话。完成后更新已有说明。
