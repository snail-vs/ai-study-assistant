# 课程需求：目标与基础多选

## 目标

把课程需求确认页中的学习目标与个人基础改为可多选，并允许补充自定义描述；选择结果作为结构化课程需求随大纲与课程生成流程传递，为后续个人学习画像保留稳定字段。

## 实施

1. 扩展前后端 `CourseBrief`：增加 `learningGoals`、`priorKnowledgeLevels` 与可选的自定义文本字段，同时保留既有单值字段以兼容已有课程和模型结果。
2. 调整需求采集 Agent 的 schema、提示词和 mock，使模型理解并利用这些数组字段，不会因一项答案覆盖另一项。
3. 在需求确认页提供两个独立的可多选标签组与“补充说明”输入；变更会清除已生成/已确认大纲，确保大纲和课程始终对应当前画像。
4. 更新 OpenAPI 生成类型与前后端测试，验证多选、自定义内容和大纲请求均保留这些字段。

## 验证

- 后端 unittest 全量运行。
- 前端 Vitest、类型检查和构建。
