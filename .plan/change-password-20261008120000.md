# 设置中心修改密码

- 新增“账号与安全”分类，表单包含当前密码、新密码、确认密码；复用现有设置中心样式与 API 客户端。
- 新增 `POST /api/v1/auth/password`（客户端路径 `/auth/password`），JSON 使用 `currentPassword`、`newPassword`，新密码沿用注册的 8–200 字符要求。成功返回 204。
- 接口通过现有 Session Cookie 获取当前用户；校验当前密码后，用现有 scrypt 更新密码哈希；同一事务撤销该用户所有旧会话并创建当前浏览器的新会话，更新 Cookie。拒绝未登录、当前密码错误和与当前密码相同的新密码。
- 前端表单局部显示错误/成功状态，提交期间禁用重复提交，成功清空密码；密码只保存在组件短期内存，不写浏览器存储。
- 并行实现后端接口/行为回归测试和前端设置表单/认证 store。集成方维护 OpenAPI 契约、生成类型和认证文档。
- 验证：后端针对密码、会话及用户隔离的测试；实际 HTTP 密码变更及重新登录；浏览器操作设置页验证失败/成功状态、密码清空以及窄屏可用性；前端类型检查/构建与相关现有测试。
