# 笔记体验重构实施计划

## 目标

把现有单列抽屉重构为可检索、可快速切换的笔记工作区，降低查找、记录和整理笔记的操作成本，同时保持现有笔记 API 兼容。

## 实施范围

1. 重构 `NotesDrawer.vue`：桌面端双栏布局、搜索和知识卡筛选、清晰的笔记摘要、沉浸式编辑区、字数与保存状态、键盘快捷键和可访问性语义。
2. 增强 notes store：公开加载/保存/删除状态及局部错误，让失败可见并阻止重复提交。
3. 调整 `App.vue` 接线，向笔记工作区传递 dirty/loading/saving/error 状态。
4. 重写笔记相关样式，覆盖暗色/亮色与移动端单栏布局。
5. 增加组件和 store 测试，验证搜索筛选、快捷保存、状态反馈和异常路径。

## 验证

- 运行前端笔记相关测试。
- 运行前端完整测试、类型检查与构建。
