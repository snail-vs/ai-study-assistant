  生成邀请码：

  uv run --project backend python -m backend.scripts.create_invite

  生产环境可以执行：

  kubectl exec -n studycenter deploy/studycenter-backend -- \
    uv run --project /app/backend python -m backend.scripts.create_invite

  命令会输出一次明文邀请码，数据库只保存哈希值。

  生产环境建议配置：

  STUDYCENTER_COOKIE_SECURE=true
  STUDYCENTER_SESSION_DAYS=30

  已有开发数据的处理方式：

  - Alembic 会创建一个不可登录的 __legacy__ 用户；
  - 第一个使用邀请码注册的真实用户会自动接管原有课程、笔记、会话和 Provider 配置；
  - 不需要手动修改原有数据；
  - 生产环境的 STUDYCENTER_ENCRYPTION_KEY 必须与开发环境一致。

  当前还没有实现密码找回、登录限流、邀请码管理后台和 CSRF 防护。公网正式开放前，这些属于下一阶段安全加固。
