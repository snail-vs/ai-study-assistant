## 修改密码

- 登录后进入“设置 → 账号与安全”，输入当前密码、新密码和确认新密码。
- 新密码为 8–200 个字符，不能与当前密码相同；密码中的空格不会被去除。
- 修改成功后清空表单，当前浏览器保持登录；该账号的其他设备和浏览器需用新密码重新登录。
- 当前密码错误、两次新密码不一致或密码长度不合法时，不会修改密码。
- 接口：`POST /api/v1/auth/password`，JSON 为 `{ "currentPassword": "...", "newPassword": "..." }`。
  成功返回 `204` 并更新 HttpOnly Session Cookie；未登录返回 `401`，当前密码错误或新旧密码相同返回 `400`，参数校验失败返回 `422`。
- 服务端复用 scrypt 哈希；更新密码、撤销旧会话和创建当前新会话在同一事务完成。

  当前还没有实现密码找回、登录限流、邀请码管理后台和 CSRF 防护。公网正式开放前，这些属于下一阶段安全加固。
